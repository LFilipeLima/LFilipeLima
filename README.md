## Projetos em destaque

### [WaterPath — TCC](https://github.com/cc24139/WaterPath_TCC)

Plataforma para relacionar dados e imagens de rios e lagos, apoiando a análise e a predição da qualidade da água ao longo do tempo. Inclui a criação de um modelo de machine learning e um modelo YOLO.

**Tecnologias:** Next.js, TypeScript, Python, FastAPI, visão computacional, .NET e Docker.

### [Meownagement](https://github.com/cc24139/Meownagement)

Aplicativo mobile gamificado para controle financeiro, com registro de receitas e despesas, metas, resumos, fórum e sistema de recompensas.

**Tecnologias:** Flutter, C# e SQL Server.

### [Compilador em C](https://github.com/cc24139/CompiladorC)

Implementação acadêmica de componentes de um compilador, incluindo análise léxica, análise sintática e tabela de símbolos.

**Tecnologias:** C.
